## Featured Cybersecurity Projects

### 1. AI Code Risk Analyzer

**Repository:** [AI-Code-Risk-Analyzer](https://github.com/Jaspinder-12/AI-Code-Risk-Analyzer)

A Python-based security analysis project designed to identify potentially unsafe patterns in AI-generated Python code.

**Key features:**
- Detects potential SQL injection patterns.
- Identifies command injection risks.
- Flags unsafe `eval()` and `exec()` usage.
- Checks for possible path traversal vulnerabilities.
- Detects potential hardcoded secrets.
- Produces structured JSON analysis results.
- Includes risk levels, vulnerability descriptions, line references, and suggested fixes.

**Technologies:** Python, Flask, AI integration, REST API, JSON

**Status:** Early development. The tool is intended to support code reviews, not replace professional security testing.

### 2. MGR-S: Multi-GPU Runtime System

**Repository:** [MGR-S-Complete](https://github.com/Jaspinder-12/MGR-S-Complete)

**Key areas:**

- Multi-GPU execution coordination.
- Memory ownership and synchronization concepts.
- Timeline-based synchronization.

**Technologies:** C++, Vulkan, Qt
