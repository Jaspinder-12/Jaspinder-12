## 🚀 Featured Projects

### 1. AI Code Risk Analyzer

**Repository:** [AI-Code-Risk-Analyzer](https://github.com/Jaspinder-12/AI-Code-Risk-Analyzer)

A Python-based security analysis project designed to identify potentially dangerous patterns in AI-generated Python code.

**Key Features:**
- Detects potential SQL injection vulnerabilities.
- Identifies command injection patterns.
- Flags unsafe `eval()` and `exec()` usage.
- Checks for potential path traversal vulnerabilities.
- Identifies hardcoded secrets and credentials.
- Produces structured JSON analysis.
- Includes risk levels, vulnerability descriptions, line numbers, and suggested fixes.

**Technology:** Python, Flask, AI model integration, REST API, JSON

**Status:** Active development.

### 2. MGR-S: Multi-GPU Runtime System

**Repository:** [MGR-S-Complete](https://github.com/Jaspinder-12/MGR-S-Complete)

An experimental software runtime project exploring explicit workload distribution and coordination across multiple GPU execution nodes.

**Key Features:**
- Explores multi-GPU workload distribution.
- Implements concepts around task and tile decomposition.
- Investigates memory ownership and synchronization.
- Explores timeline-based synchronization.
- Includes runtime observability and monitoring concepts.
- Investigates heterogeneous GPU configurations.

**Technology:** C++, Vulkan, GPU Runtime Concepts

**Status:** Experimental development.
